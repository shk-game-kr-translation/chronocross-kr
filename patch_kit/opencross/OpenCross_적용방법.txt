OpenCross 한글 적용 방법 (CCRDE 한글패치 v{ver})
================================================================

OpenCross(opencross.exe)로 크로노 크로스를 실행하는 분만 하면 됩니다.
게임 원래 실행 파일(CHRONOCROSS.exe)로 하는 분은 이 폴더를 쓰지 않아도 됩니다.


[이 폴더로 고쳐지는 것]
  - OpenCross 안에 영어로 박혀 있는 문구 39개를 한글로 바꿉니다.
      전투 메뉴(공격 / 엘리멘탈 / 방어 / 도망), 상태이상 이름, 대상(아군 전체 등),
      타이틀(새 게임 / 이어하기 / 설정 / 종료), 이름 입력 화면, 파티 교체 화면 등
  - 전투 결과창의 회복 메뉴, 사용한 엘리멘탈 이름 등에서 한글 일부가 빈칸으로 나오던 문제를 고칩니다.


[적용 순서]
  1. 먼저 한글패치 본체를 설치합니다. (압축 안의 설치방법.txt 대로 data 폴더 덮어쓰기)
  2. OpenCross 를 완전히 끕니다.
  3. 이 폴더의 파일 2개를 opencross.exe 가 있는 폴더에 복사합니다.
       OpenCross_한글패치.bat
       opencross_kr.ps1
  4. OpenCross_한글패치.bat 를 더블클릭합니다.
  5. 검은 창에 아래처럼 나오면 끝입니다. 아무 키나 눌러 창을 닫으세요.
       적용 완료. 원본 백업: ...\opencross.exe.orig
       영어 문구 한글화: 39/39
       결과창 회복 메뉴 글자 수정: 적용됨
       한글 글자 빠짐 수정: 적용됨
  6. OpenCross 를 실행합니다. 게임 언어는 English 로 둡니다.


[이럴 때는]
  - "opencross.exe에 쓸 수 없습니다" 가 나오면 OpenCross 가 켜져 있는 것입니다. 끄고 다시 실행하세요.
  - "이미 적용되어 있습니다" 는 이미 적용된 상태라는 뜻입니다. 그대로 쓰면 됩니다.
  - OpenCross 가 자동 업데이트되면 다시 영어로 돌아올 수 있습니다. 그때 4번만 다시 하세요.
  - 새 OpenCross 버전에서 "건너뜀" 이 나오면 그 부분은 그 버전에 맞지 않아 바꾸지 않은 것입니다.
    나머지는 적용되어 있습니다. 제보해 주시면 맞춰 고치겠습니다.
  - Windows 보안 경고가 뜨면 "추가 정보 → 실행" 을 누르세요. (PowerShell 스크립트로 opencross.exe 만 고칩니다)


[원래대로 돌리기]
  opencross.exe 를 지우고, opencross.exe.orig 의 이름을 opencross.exe 로 바꾸면 됩니다.


[참고]
  - opencross.exe 를 직접 배포하지 않고, 사용자의 opencross.exe 안의 글자와 코드 일부만 바꿉니다.
  - OpenCross 는 이 한글패치와 별개의 프로그램입니다. OpenCross 자체 문제는 OpenCross 제작자에게,
    한글 표시 문제는 아래로 제보해 주세요.
