크로노 크로스: 래디컬 드리머즈 에디션 비공식 한글 패치 v{ver} (덮어쓰기판)
================================================================

크로노 크로스 본편과 수록작 「래디컬 드리머즈」의 문장을 한국어로 옮긴 패치입니다.


[대상]
  Steam PC판 CHRONO CROSS: THE RADICAL DREAMERS EDITION


[설치] — 파일 덮어쓰기
  1. 게임을 완전히 종료합니다.
  2. 게임 폴더를 엽니다.
     Steam 라이브러리에서 게임 우클릭 → 관리 → 로컬 파일 보기
     (CHRONOCROSS.exe 와 data 폴더가 있는 곳)
  3. (권장) 게임 폴더의 data 폴더 안에 있는 아래 4개 파일을 다른 곳에 복사해 백업해 둡니다.
       lang.dat, font.dat, ui.dat, radicaldreamers.dat
  4. 압축을 푼 폴더 안의 data 폴더를 게임 폴더에 그대로 끌어다 놓고 "덮어쓰기" 합니다.
  5. 게임 언어를 English 로 둔 채 실행합니다.
     (한국어 문장이 영어 자리에 들어가 있으므로 다른 언어에서는 한글이 나오지 않습니다.)


[삭제 / 원래대로]
  백업해 둔 파일 4개를 다시 data 폴더에 덮어쓰거나,
  Steam 에서 게임 우클릭 → 속성 → 설치된 파일 → "게임 파일 무결성 확인" 을 하면 원래대로 돌아옵니다.


[업데이트]
  새 버전의 data 폴더를 똑같이 덮어쓰면 됩니다.
  Steam 이 게임을 업데이트하면 패치가 풀릴 수 있습니다. 그때도 다시 덮어쓰세요.
  게임 업데이트로 파일 구조가 바뀌었다면 이 버전의 파일을 덮어쓰지 마세요(게임이 실행되지 않을 수 있습니다).


[바뀌는 파일]
  data\lang.dat            본편 대사·메뉴·아이템·기술 이름 등 (영어 자리에 한국어)
  data\font.dat            본편 글꼴에 한글 추가 (ESC 메뉴 글꼴 포함)
  data\ui.dat              일시정지 화면 글꼴에 한글 추가
  data\radicaldreamers.dat 래디컬 드리머즈 본문과 글꼴
  실행 파일(exe)은 수정하지 않습니다.


[알려진 문제]
  - 그림으로 된 글자(타이틀·이름 입력 화면·조작법 안내·메뉴 항목 이름 등)는 아직 영어입니다.
  - 래디컬 드리머즈의 주인공 이름은 대사에서 항상 「세르쥬」로 나옵니다.
    이름 입력 화면에서 다른 이름을 넣어도 대사에는 반영되지 않습니다
    (기본 이름 Serge 가 실행 파일 안에 있어 데이터 파일만으로는 바꿀 수 없기 때문입니다).
  - 세이브 데이터는 바꾸지 않습니다. 패치를 지울 계획이면 세이브를 따로 백업해 두세요.
  - 체력·레벨 등 일부 짧은 표기(Lv, Sta. 등)는 화면 배치 때문에 영어로 두었습니다.
