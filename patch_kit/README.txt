크로노 크로스: 래디컬 드리머즈 에디션 비공식 한글 패치 v0.1.0
================================================================

수록작 「래디컬 드리머즈 -훔칠 수 없는 보석-」의 본문을 한국어로 옮긴 패치입니다.
크로노 크로스 본편 한글화는 다음 버전에서 진행합니다.

배포처: https://github.com/shk-game-kr-translation/chronocross-kr


[대상]
  Steam PC판 CHRONO CROSS: THE RADICAL DREAMERS EDITION
  data\radicaldreamers.dat 원본 SHA-256: a6c8179b37eca646e741c395504d8714e2701cef027308556d8f5906be09a142
  게임 파일이 이와 다르면(업데이트 등) 패처가 아무것도 바꾸지 않고 멈춥니다.


[설치]
  1. 게임을 완전히 종료합니다.
  2. 받은 zip 파일의 압축을 아무 곳에나 풉니다. (폴더째로 풀어야 합니다. patch 폴더가 함께 있어야 합니다.)
  3. "한글패치_적용.bat" 을 더블클릭합니다.
     - Steam 라이브러리에서 게임 폴더를 자동으로 찾습니다.
     - "게임 폴더를 찾지 못했습니다" 가 나오면, 압축을 푼 폴더를 통째로 게임 폴더
       (RADICALDREAMERS.exe 가 있는 곳. Steam 에서 게임 우클릭 → 관리 → 로컬 파일 보기) 안에 넣고 다시 실행하세요.
  4. "한글 패치를 적용했습니다." 가 나오면 완료입니다. 아무 키나 눌러 창을 닫습니다.
  5. 게임 언어를 English 로 둔 채 실행하고, 런처에서 RADICAL DREAMERS 를 고릅니다.
     (한국어 문장이 영어 자리에 들어가 있으므로 다른 언어에서는 한글이 나오지 않습니다.)

  Windows 보안 경고(SmartScreen)가 뜨면 "추가 정보 → 실행" 을 누르세요.
  패처는 Windows 기본 PowerShell 로 동작하며 다른 프로그램이 필요 없습니다.


[삭제 / 원래대로]
  "원본_복구.bat" 을 실행하면 패치 전에 만든 백업(data\radicaldreamers.dat.kr_backup)으로 되돌립니다.
  백업이 없거나 문제가 생기면 Steam 에서 게임 우클릭 → 속성 → 설치된 파일 → "게임 파일 무결성 확인" 을 하세요.


[업데이트]
  새 버전을 받으면 그대로 "한글패치_적용.bat" 을 실행하면 됩니다. (이전 버전이 적용돼 있어도 백업에서 다시 만듭니다.)
  Steam 이 게임을 업데이트해 파일이 바뀌면 패치가 풀릴 수 있습니다. 그때도 다시 실행하세요.


[알려진 문제]
  - 이름 입력 화면과 기본 이름(Serge), 조작법 안내 화면 등 그림으로 된 글자는 아직 영어입니다.
  - 본편(크로노 크로스)은 아직 번역되지 않았습니다.
  오역·버그 제보: 배포처의 Issues 에 장면과 문구를 적어 주세요.


[패치가 하는 일]
  data\radicaldreamers.dat 한 파일만 바꿉니다. 실행 파일(exe)은 수정하지 않습니다.
  패치 안에는 한국어 문장과 한글 글리프만 들어 있으며, 원문과 원본 글꼴은 사용자의 게임 파일에서 읽어 조합합니다.
  조합 결과가 정해진 해시와 일치할 때만 파일을 교체합니다.
